# LEXIA v2

**LEXIA is an AI coding assistant designed to help users with programming, coding questions, and general technical tasks.**

The project includes a web application and a Visual Studio Code extension, making LEXIA accessible through a web page or directly inside the code editor.

## Features

* **AI Assistant:** Ask questions and get AI-generated responses.
* **Web Application:** Interact with LEXIA through a simple chat interface.
* **VS Code Extension:** Access LEXIA directly inside Visual Studio Code.
* **Code Support:** Get explanations, programming guidance, and code examples.

## Project Structure

* `backend/` — API and AI provider integration.
* `frontend/` — LEXIA web application.
* `extension/` — LEXIA VS Code extension.
